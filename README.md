# Miller Perez — Web Dev Portfolio

Personal portfolio site, live at [peremiller.github.io/webdevportfolio](https://peremiller.github.io/webdevportfolio/).

A single self-contained `index.html` — no frameworks, no build step:

- Dark theme with gradient accents, glow orbs, and a subtle grid backdrop
- Typewriter hero (a nod to the original 2019 version of this site)
- Scroll-reveal animations via `IntersectionObserver`, with `prefers-reduced-motion` support
- Scrollspy nav + mobile hamburger menu
- Real featured projects with live links
